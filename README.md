# ADT project page

Static academic website for **Multimodal Action Diffusion for Robust End-to-End Autonomous Driving**.

Live URL: https://jorgedanielrodrividal.github.io/multimodal-e2e-autonomous-driving/

GitHub Pages serves the root of `main`. No build step or external JavaScript dependencies are required. Preview with `python -m http.server 8000`.

- All numerical results come from arXiv:2606.02105, Tables 1, 2, 4 and 5.
- The four supplied paper figures are retained without image changes.
- The source code release remains **coming soon**.
- Website structure is inspired by LoRAtorio, with original implementation, red branding and altered chart layouts. No related-work section.
